# The Kahlert Café Website

Next.js rebuild of the website for The Kahlert Café — an inclusive farm-to-able community café in Sparks, MD, providing meaningful employment and culinary training for adults with intellectual and developmental disabilities.

Originally built on Webflow; now migrating to a modern Next.js + Vercel stack with GitHub for source control.

## Features (Homepage)
- Responsive design
- Mission-driven content
- Order Online integration (Toast)
- Facebook link
- Hours, address, and contact info

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deployment
Connect this repository to Vercel for automatic deployments. Staging URL will be available on `*.vercel.app`.

## Project Structure
- `src/app/page.tsx` — Homepage
- Tailwind CSS for styling
